## Added scope: PhotoCraft Android feature parity (2026-10-22)

**The request is for implementation, not merely a UI mock-up.** These are required deliverables in subsequent isolated DeckCraft-specific commits before production release; the **baseline candidate workflow does not implement these features**. Do not silently drop features to get a green build.

1. **Native individual-font import**: Add DeckCraft's own menu action, e.g. `File/Options → Fonts → Import Font`, using Android SAF `ACTION_OPEN_DOCUMENT` for `.ttf`/`.otf` (accept `.ttc` where DeckCraft can parse it), read/copy safely into DeckCraft-private persistent fonts (reject invalid/non-font files, respect size caps and avoid unsafe replacement), register with `deckcraft_fonts::FontDb::global().add_font(bytes)`, refresh the font family UI and render; clearly report loaded faces, duplicates and failures. Test Montserrat regular/semibold and complex-script fallback; maintain presentation text/font fidelity. **Do not create a floating Custom Fonts window.**
2. **Shared ArtCraft folder**: Keep `Documents/ArtCraft-Fonts` as a user-selected Android SAF document tree shared by separately-permissioned suite apps. Persist DeckCraft's own URI grant, enumerate selected folder and supported font files within reasonable byte/file limits, import/register faces, support `Select Shared Font Folder` / `Refresh Shared Fonts` and optionally `Disconnect`; report counts/errors and handle revoked grants or missing folder by falling back to private/system/embedded fonts without crashing. Do not presume that permissions granted to PhotoCraft transfer automatically to DeckCraft. Never write shared fonts without explicit action.
3. **Help → Check for Updates**: Reuse the safe PhotoCraft GitHub release-check pattern with DeckCraft-specific repository `KosmosSG/artcraft-android` release metadata and **package identity**, accurate installed version and latest verified Android release. Offer manual check plus saved `Check automatically at startup` preference; run on app startup only when enabled and network available, nonblocking with timeout/clear offline error and cancel-safe UI. Separate official upstream stable source discovery from user-installable signed APK updates; only offer releases with a verified matching permanent certificate/package/ABI/greater versionCode. Never auto-install, downgrade or link to a temporary-key candidate.
4. **Tablet / shortcuts**: Keep Android IME composition and modifier-key fixes, clipboard/selection, undo/redo. Use the actual `SlideApp::run`/engine command registry to back physical shortcut defaults and user remapping; add a **docked, optional** Shortcut Pad (not a floating window), persistent visibility and button mapping. Verify touch/stylus drawing, thumbnails, zoom, trackpad, orientation changes and fullscreen/lifecycle on the HONOR MagicPad 4.
5. **Other PhotoCraft compatibility work**: Prefer SAF for open/save/save-as/export, handle permission cancellation/revocation; truthful graphics adapter/backend/driver diagnostics and an honest CPU renderer/fallback (do not claim DeckCraft uses PhotoCraft's GPU canvas, since DeckCraft renders slides through a different pipeline); preserve slideshow navigation and supported media; assess Android PrintManager/external display only after platform API review.
6. **Release and regression proofs**: Add app-specific tests of font registration and reload, presentation Save→Close→Open, PDF/PPTX/PNG exports, malformed fonts, missing files, license compliance, offline updater responses, physical shortcut mapping, crash/lifecycle fallback, and provenance. Use representative authored decks and clearly list unsupported PowerPoint round-trips. Capture screenshots/logs only when the physical tablet is available; compilation alone is not a device pass.

**PhotoCraft reference for porting (read-only):** `KosmosSG/artcraft-android@photocraft-gpu-font-restore`, especially `adapters/photocraft/src/lib.rs`, Java SAF Activity and `patches/photocraft-menus.patch`; and the latest signed PhotoCraft update-check workflow/release policy. The reference implements asynchronous shared-font recovery and update checks, but PhotoCraft's UI/window and renderer APIs are different. DeckCraft upstream at v0.9.0 exposes `FontDb::add_font(Vec<u8>) -> usize`, the `SlideApp::run` command gateway and existing file/print/export hooks, which should be used instead of copying PhotoCraft's implementation unchecked.

**Feature state today:** scoped and source-reviewed; none of the newly requested font-import, shared-font UI, DeckCraft-specific update menu/preferences, or Shortcut Pad functions are established as shipped or tablet-tested by this PR. Implement and compile them before promoting this candidate to a signed release.

## Candidate follow-up (October 22): native font import + launcher verification

- Added `patch_deckcraft_fonts.py`, applied **only** to the pinned DeckCraft source in the disposable candidate checkout. It introduces `app.importFont` in the existing command palette and Help command catalogue, opens Android's existing asynchronous SAF document picker, accepts TTF/OTF/TTC with filename/header/20 MiB limits, and registers new faces through `deckcraft_fonts::FontDb::global().add_font`. It reports errors and duplicates rather than treating arbitrary files as fonts. **This initial import is session-only**; it does not yet persist imported fonts, request a shared tree URI, refresh shared folders or provide the final menu placement.
- The previous candidate compiled but failed a **false-negative ZIP filename assertion**: Android AAPT2 minifies compiled resource paths into opaque names such as `res/-B.png`. The updated verifier checks the resource table's actual launcher/adaptive resource identities and compares APK launcher pixels with the user-approved Dk artwork. A green result is still required before declaring the icon integrated.
- Existing DeckCraft file-open, slide-rendering and export functionality is left intact. No signing secrets, production keys, public releases or sister apps are touched.
- Still pending: passing candidate CI with the font patch, persistent per-app font storage, SAF shared-folder select/refresh/revocation, updater menu and opt-in startup preference, configurable shortcuts/Shortcut Pad, full tablet/regression tests, signing history and permanent release gates.
